# LeetCode 169 多数元素
> 难度：简单 | 标签：数组、哈希、分治、摩尔投票
题目链接：https://leetcode.cn/problems/majority-element/

## 题目描述
给定一个大小为 n 的数组 `nums` ，返回其中的多数元素。
多数元素：出现次数 **大于 ⌊n/2⌋** 的元素。
题目保证数组非空，并且一定存在多数元素。

进阶要求：时间 O(n)，空间 O(1)

## 解题思路：摩尔投票法
核心思想：
多数元素的数量超过一半，可以把其他元素当成“对立票”，两两抵消。
1. 设置候选值 candidate、票数 count。
2. count=0 时，将当前数字选为新候选。
3. 当前数字等于候选，票数+1；否则票数-1。
4. 因为一定存在多数元素，遍历完成后 candidate 即为答案。

> 优势：只遍历数组一次，只用两个变量，满足进阶的 O(n)、O(1)。


## 复杂度分析

- 时间复杂度：O (n)，数组仅遍历一遍
- 空间复杂度：O (1)，仅 2 个临时变量，不随数组大小变化

## 踩坑记录

1. 摩尔投票法**前提：题目保证一定存在多数元素**。如果题目不保证，最后拿到候选后还需要再遍历一次数组，校验候选出现次数。
2. C 语言数组传参到函数，会退化成指针，函数内部不能直接用`sizeof`求数组长度，必须外部传入`numsSize`。
3. 不要混淆：大于 `n/2`，不是大于等于。
