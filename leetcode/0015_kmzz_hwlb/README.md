# LeetCode 234. 回文链表

难度：简单
标签：链表、快慢指针、链表反转
题目链接：[https://leetcode.cn/problems/palindrome-linked-list/](https://leetcode.cn/problems/palindrome-linked-list/)

## 题目描述

给你一个单链表的头节点 `head`，判断该链表是否为回文链表。

- 回文：从前往后遍历 和 从后往前遍历，节点数值完全一样。
是回文返回 `true`，否则返回 `false`。

示例 1
输入：`head = [1,2,2,1]`，输出：`true`
示例 2
输入：`head = [1,2]`，输出：`false`

> 
> 进阶要求：时间 \(O(n)\)，空间 \(O(1)\)，**不能额外开数组保存值**，原地操作链表。

## 解题思路（进阶最优方案：快慢指针 + 反转后半段链表）

1. **快慢指针**：慢指针一次走 1 步，快指针一次走 2 步。快指针走到末尾时，慢指针刚好到链表中点。
2. **反转后半段链表**：以慢指针为起点，把后半部分链表反转。
3. **双指针比对**：一个指针从头，一个从反转后的后半段开头，逐个对比 val。全部相等就是回文。
4. （可选）恢复链表：比对完成后，把后半段链表恢复原样（不恢复也能 AC，但工程代码建议恢复）

### 复杂度

- 时间复杂度：\(O(n)\)，总共遍历链表常数次
- 空间复杂度：\(O(1)\)，只使用常数个指针，满足进阶要求

## 踩坑记录（本地调试高频 BUG）

1. 快慢指针循环条件：`fast->next != NULL && fast->next->next != NULL`，不要写错，写错会中点定位错误。
2. 对比循环条件用 `p2 != NULL`：后半段更短，p2 先走完。
3. 记得引入头文件 `#include <stdbool.h>`，否则`bool true false`会报类型未定义。
4. 奇数长度链表，中间那个节点不用参与比较，天然不影响回文判断。
5. 快慢指针循环条件不要写错，会找错中点。
6. 比对结束恢复链表，工程代码好习惯，防止原链表结构被修改。
7. 空链表、单节点链表直接返回 true。
