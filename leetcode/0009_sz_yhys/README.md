# LeetCode 136. 只出现一次的数字
题目链接：https://leetcode.cn/problems/single-number/

## 题目描述
给你一个**非空**整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。
要求：线性时间复杂度，仅使用常量额外空间。

## 解题思路
使用**异或位运算**。
异或三条核心性质：
1. `a ^ a = 0`：同一个数字异或自己，结果为0
2. `a ^ 0 = a`：任何数字异或0，值保持不变
3. 异或满足交换律、结合律，数字遍历顺序不影响最终结果

思路：把数组所有数字依次异或。成对出现的数字相互抵消变成0，最后剩下的结果，就是唯一只出现一次的数字。

示例：数组 `[4,1,2,1,2]`
`4 ^ 1 ^ 2 ^ 1 ^ 2 = 4 ^ (1^1) ^ (2^2) = 4 ^ 0 ^ 0 = 4`

## 复杂度分析
- 时间复杂度：$O(n)$，仅遍历数组一次
- 空间复杂度：$O(1)$，只使用1个变量保存结果，满足题目常量空间要求

## 踩坑记录

1. 哈希表解法虽然好理解，但是需要额外内存，不满足本题 O (1) 空间限制，不能作为本题标准答案。
2. 数组传入函数后会退化成指针，**函数内部不能使用 sizeof 求数组长度**，数组长度需要在 main 函数预先计算后传入。
3. `^` 是位运算异或，**不是求幂运算**，不要和数学上的平方符号混淆。
4. Windows Device Guard 策略可能拦截 MinGW 生成的 exe 运行，代码本身没有语法错误，只是系统阻止程序执行，不影响提交代码到 GitHub 仓库。
