# LeetCode 160 相交链表
> 难度：简单 | 标签：链表、双指针
题目链接：https://leetcode.cn/problems/intersection-of-two-linked-lists/

## 题目描述
给你两个单链表的头节点 `headA` 和 `headB` ，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 `null` 。

### 核心思路：双指针法
设链表A长度为 a，链表B长度为 b。
指针 pA 走完A，再走B；指针 pB 走完B，再走A。
- 如果两链表相交：两个指针会**同时到达相交点**
- 如果不相交：两个指针最后会同时走到 `NULL`，循环退出，返回NULL
> 原理：`a + b = b + a`，两个指针走过的总路程相等，最终一定相遇。

## 复杂度分析

- 时间复杂度：O (a + b)，最多遍历两个链表各一次
- 空间复杂度：O (1)，只使用了两个指针，**常数额外空间**

## 踩坑记录

1. C 语言结构体定义，`}`后面**必须写分号**，漏写会让编译器解析错乱，报错跑到下一行，误导排查。
2. LeetCode 在线提交不用写`newNode`和`main`，本地调试才需要。
3. 判断相等 `pA != pB` 是**比较地址**，不是比较节点里面 val 的值！两个节点 val 相同不代表相交，必须内存地址一致。
