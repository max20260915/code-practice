# LeetCode 104. 二叉树的最大深度
题目链接：https://leetcode.cn/problems/maximum-depth-of-binary-tree/

## 题目描述
给定一个二叉树 `root`，返回其最大深度。
二叉树的最大深度是指从根节点到最远叶子节点的最长路径上的节点总数。

> 叶子节点：没有左右子节点的节点。

## 解题思路（递归 DFS）
核心思想：**一棵树的深度 = 1（当前节点） + 左子树深度、右子树深度两者的最大值**
1. 如果当前节点是 `NULL`（空），深度为0，直接返回。
2. 递归求左子树最大深度。
3. 递归求右子树最大深度。
4. 当前节点深度 = `1 + max(左深度, 右深度)`。

简单大白话：看左边树有多深、右边树有多深，取更深那一条，加上自己这一层。

## 复杂度分析
- 时间复杂度：$O(n)$，n为节点总数，每个节点访问1次
- 空间复杂度：$O(h)$，h是树高度，递归调用栈占用空间；最坏情况单链树 $O(n)$，平衡树 $O(logn)$

## 踩坑记录

1. 容易把返回值写成 `max(left, right)`，忘记 + 1，结果深度全部少 1。
2. 递归终止条件写错，写成 `return 1`，会造成深度计算偏大。
3. 本地写代码时，**必须手动构建二叉树节点**，LeetCode 平台会自动构造输入，本地不写`createNode`和 main 函数无法运行。
4. 递归深度很大时会栈溢出，可以用 BFS 层序遍历迭代解法。
