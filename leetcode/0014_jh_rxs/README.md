# LeetCode 226. 翻转二叉树

难度：简单
标签：二叉树、递归、DFS
题目链接：[https://leetcode.cn/problems/invert-binary-tree/](https://leetcode.cn/problems/invert-binary-tree/)

## 题目描述

给你一棵二叉树的根节点 `root`，翻转这棵二叉树，并返回其根节点。
翻转：**每一个节点的左子节点、右子节点互相交换**。

示例 1
输入：`root = [4,2,7,1,3,6,9]`
输出：`[4,7,2,9,6,3,1]`

## 解题思路

### 递归 DFS（最直观，推荐）

1. 终止条件：如果当前节点为 `NULL`，直接返回
2. 交换当前节点的左孩子和右孩子
3. 递归翻转左子树
4. 递归翻转右子树

> 
> 核心：从上到下，每个节点都互换左右子树。

## 复杂度分析

- 时间复杂度：\(O(n)\)，每个节点访问一次
- 空间复杂度：\(O(h)\)，h 为树高度，递归栈开销；最坏单链树 \(O(n)\)

## 踩坑记录（本地调试）

1. **交换节点一定要临时变量 temp**
不能直接 `root->left = root->right`，会直接丢失左子树地址。
2. 空树直接返回 `NULL`，不做任何操作，防止访问空指针。
3. 递归顺序：交换之后再递归左右，先处理当前节点，再往下处理子节点。
4. 内存：本地 malloc 新建节点，LeetCode 平台会自动管理内存，提交版本不用手动 free。
