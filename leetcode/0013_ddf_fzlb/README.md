# LeetCode 206. 反转链表

难度：简单
标签：链表、双指针、递归
题目链接：[https://leetcode.cn/problems/reverse-linked-list/](https://leetcode.cn/problems/reverse-linked-list/)

## 题目描述

给你一个单链表的头节点 `head`，将整个链表反转，并返回**反转后的新头节点**。

示例：

- 输入：`1 -> 2 -> 3 -> 4 -> 5`
- 输出：`5 -> 4 -> 3 -> 2 -> 1`

## 解题思路（两种标准解法）

### 解法一：迭代双指针（最推荐、最优解）

核心思想：**逐个节点反转指向**
用三个指针完成全程遍历：

- `prev`：前驱节点（初始 NULL）
- `cur`：当前遍历节点
- `next`：临时保存下一节点（防止断链丢失链表）

流程：

1. 先保存后面节点 `next = cur->next`
2. 当前节点反向指向前面 `cur->next = prev`
3. `prev`、`cur` 整体后移
4. 遍历结束，`prev` 就是新链表头

### 解法二：递归（简洁但占用栈空间）

从**最尾部**开始反向修改指针：

1. 递归深入到最后一个节点（新头节点）
2. 回程时让后一个节点指向自己
3. 清空正向旧指针，避免成环

## 复杂度分析

### 迭代版

- 时间复杂度：\(O(n)\) 遍历一次链表
- 空间复杂度：\(O(1)\) 仅三个指针，常数空间

### 递归版

- 时间复杂度：\(O(n)\)
- 空间复杂度：\(O(n)\) 递归栈深度等于链表长度

## 踩坑记录（本地调试高频 BUG）

1. **C 语言必须前置函数声明**
如果 `printList / newNode` 定义在 main 后面，不加声明会报：`implicit declaration of function` 编译错误。
2. **next 必须是指针**
错误写法：`struct ListNode next;`（结构体变量）
正确写法：`struct ListNode *next;`（指针）
3. **迭代必须先保存 next**
如果直接写 `cur->next = prev`，会**丢失整条后续链表**。
4. **递归必须置空 head->next**
不写 `head->next = NULL` 会形成**环形链表死循环**。
5. 空链表、单节点链表代码天然兼容，无需特殊处理。
