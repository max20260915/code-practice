# LeetCode 338. 比特位计数 README.md

> 
> 题目链接：[https://leetcode.cn/problems/counting-bits/](https://leetcode.cn/problems/counting-bits/)

## 题目描述

给你一个整数 `n` ，对于 `0 <= i <= n` 中的每个 `i` ，计算其二进制表示中 `1` 的个数 ，返回一个长度为 `n + 1` 的数组 `ans` 作为答案。

示例：
输入：`n = 5`
输出：`[0,1,1,2,1,2]`
解释：

- 0 → 0 → 0 个 1
- 1 → 1 → 1 个 1
- 2 → 10 → 1 个 1
- 3 → 11 → 2 个 1
- 4 → 100 → 1 个 1
- 5 → 101 → 2 个 1

## 解题思路（动态规划）

核心公式：

```
ans[i] = ans[i >> 1] + (i & 1);
```

拆解理解：

1. `i >> 1`：相当于 `i / 2`，把二进制右移一位，去掉最低位。
例如：`5(101) >> 1 = 2(10)`
2. `i & 1`：取 `i` 的二进制最低位，结果只能是 0 或者 1。
   - 最低位是 1 → 加 1
   - 最低位是 0 → 加 0

含义：数字 `i` 的 1 的个数 = 去掉最低位之后数字的 1 的个数 + 最低位本身是不是 1。
利用已经算好的前面结果，避免重复统计，属于动态规划。

## 复杂度分析

- 时间复杂度：\(O(n)\)，只循环一次，每个数字计算一次
- 空间复杂度：\(O(n)\)，存放返回数组（不计结果数组的话是 \(O(1)\)）

## 踩坑记录

1. 数组长度是 `n+1`，范围包含 0 ~ n，很容易写成 n，造成越界。
2. `returnSize` 必须赋值为 `n+1`，LeetCode 依靠这个参数读取返回数组长度，忘记赋值会判错。
3. malloc 开辟的内存，本地测试记得 `free`，防止内存泄漏；平台提交不用手动 free。
4. 位运算优先级：`>>` 高于 `&`，公式不用额外加括号，但写复杂表达式建议加上括号提高可读性。

## 补充：其他思路（了解即可）

- 暴力法：每个数字循环 `i & (i-1)` 统计 1，\(O(n\log n)\)，效率低，不推荐。
- 另一种 DP：`ans[i] = ans[i & (i - 1)] + 1`，清除最低位的 1，也可以解题。
