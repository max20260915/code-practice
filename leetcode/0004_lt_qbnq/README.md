# LeetCode 70. 爬楼梯
> 题号：70
> 题目链接：https://leetcode.cn/problems/climbing-stairs/
> 难度：简单
> 标签：动态规划

##  题目大意
假设你正在爬楼梯。需要爬 `n` 阶你才能到达楼顶。
每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶？

##  解题思路（大白话）
爬到第n阶台阶的方法总数 = 爬到第n-1阶的方法数（再爬1阶） + 爬到第n-2阶的方法数（再爬2阶）。
本质是斐波那契数列。
**优化点：不用数组保存全部历史结果，只用3个变量滚动更新，节省内存。**
p、q、r三个变量交替向前滚动，每次循环只更新这三个值。

## ⏱复杂度
- 时间复杂度：$O(n)$，只循环n次
- 空间复杂度：$O(1)$，仅使用固定数量临时变量，不随n增大占用更多内存

## 踩坑记录
1. **本地编译缺少 main 函数**：LeetCode 平台只需要写`climbStairs`函数，但是本地 MinGW 编译运行必须写`main`入口，否则报`undefined reference to WinMain`链接错误。
2. **函数调用忘记传参**：调用`climbStairs()`时，必须传入 n，不能空括号，否则编译报错。
3. 本地环境问题：MinGW 损坏会出现 `stdio.h: No such file or directory`，代码本身没错，是编译器环境丢失头文件，需要重装 MinGW-w64。
