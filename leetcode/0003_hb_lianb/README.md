# LeetCode 0003 Merge Two Sorted Lists
题目链接：https://leetcode.cn/problems/merge-two-sorted-lists/

## 题目描述
将两个升序链表合并为一个新的 **升序** 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

## 解题思路
采用**虚拟头结点(dummy)迭代法**。
1. 创建一个虚拟头节点，用来简化链表边界判断（不用单独处理链表为空的特殊情况）。
2. 用tail指针，作为新链表的尾部，不断往后追加节点。
3. 循环比较 l1 和 l2 当前节点的值：把更小的节点接到 tail 后面，然后对应链表指针后移，tail也向后走一步。
4. 当其中一条链表遍历完，直接把剩下另一条链表剩余部分接到tail后面。
5. 返回虚拟头节点的下一个节点，就是合并后的链表。

> 不使用递归：递归写法简洁，但链表很长时会栈溢出，迭代更适合嵌入式/机器人工程场景。

## 复杂度分析
- 时间复杂度：$O(m+n)$，m、n 是两个链表节点数量，每个节点只访问一次
- 空间复杂度：$O(1)$，只新增常数个指针，没有额外开辟数组，原地拼接节点

## 踩坑记录
1. 一开始没使用 dummy 虚拟头结点，需要单独写代码判断两个链表是否为空，代码臃肿，容易漏边界情况。
2. 忘记**释放链表内存**。C 语言链表使用 malloc 开辟节点，程序结束不 free 会造成内存泄漏，嵌入式开发中内存泄漏是严重问题，机器人工程项目必须重视。
3. 写 tail = tail->next 时放错位置，导致节点重复连接，链表出现环，打印无限循环。
4. 区分：只是修改指针指向，**没有复制节点**，节省内存，适合资源受限的嵌入式设备。
