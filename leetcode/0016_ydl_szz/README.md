# LeetCode 283. 移动零
## 题目链接
https://leetcode.cn/problems/move-zeroes/
## 题意
原地将数组中全部0移动到数组末尾，**不能改变非零元素原来的先后顺序**，禁止新建数组拷贝。

## 解题思路
双指针法：
1. fast快指针循环遍历数组，寻找非0元素
2. slow慢指针负责存放非0元素，每找到一个非0就放到nums[slow]，slow自增
3. 遍历结束，slow下标往后全部赋值为0
> 进阶版本：直接交换快慢指针的值，省去第二轮循环赋值

## 复杂度分析
- 时间：O(n)
- 空间：O(1) 原地算法

## 测试样例
样例1
输入：[0,1,0,3,12]
输出：[1,3,12,0,0]

样例2
输入：[0]
输出：[0]

## 踩坑记录
1. 不能排序，排序会打乱非零元素**相对顺序**
2. 注意原地操作，不能新开数组保存结果
3. 边界：数组只有一个元素、数组全部是0、数组没有0的情况
