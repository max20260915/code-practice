# LeetCode 94. 二叉树的中序遍历
> 题号：94
> 题目链接：https://leetcode.cn/problems/binary-tree-inorder-traversal/
> 难度：简单
> 标签：二叉树、深度优先搜索、递归

##  题目大意
给定一棵二叉树的根节点 `root`，返回它的**中序遍历**结果数组。
中序遍历规则：**左子树 → 根节点 → 右子树**。

##  解题思路（大白话）
采用递归实现深度优先遍历：
1. 递归遍历当前节点的左子树，一直走到最左侧；
2. 左子树全部遍历完成后，记录当前根节点的值存入结果数组；
3. 再递归遍历当前节点的右子树。

使用动态数组存储遍历结果，`resSize` 作为指针，用来标记数组当前存放元素的下标。
`(*resSize)++`：取出当前下标存入数据，存入完成后下标自增，准备存储下一个节点值。

##  复杂度
- 时间复杂度：$O(n)$，n为二叉树节点总数，每个节点只会访问一次
- 空间复杂度：$O(n)$，结果数组占用n空间；最坏情况（单链二叉树）递归栈占用$O(n)$

## 踩坑记录
1. **数组符号写错**：数组取值必须用方括号`[]`，不能写成圆括号`()`，`res(...)`会被识别成函数调用，编译报错。
2. **C 语言区分大小写**：结构体名、函数名大小写必须前后统一，`TreeNode`不能全部小写`treenode`，否则标识符不匹配。
3. `(*resSize)++`括号不能省略，若写成`*resSize++`，逻辑完全错误。
4. 本地编译必须手动定义`struct TreeNode`，LeetCode 平台后台已经预先定义，提交代码时不需要写结构体。
5. 本地环境：MinGW 损坏会出现`stdlib.h: No such file or directory`，代码本身没问题，是编译器缺失头文件，需要重装 MinGW-w64。
6. malloc 申请的内存，本地测试要手动 free 释放，避免内存泄漏；LeetOJ 平台会自动回收内存。

##  踩坑记录

1. **镜像对比是交叉比较**：`a左 vs b右`，`a右 vs b左`，不要写成 a 左 vs b 左，这是最容易写错的逻辑错误。
2. `stdbool.h`头文件：本地使用`bool`类型必须引入，LeetCode 平台自带。
3. 递归终止条件顺序不能乱：要先判断两个节点是否为空，再取值比较，否则访问`NULL->val`会程序崩溃。
4. 区分 “相等” 和 “镜像相等”：两棵树完全相等是同位置对比；镜像要交叉对比。
