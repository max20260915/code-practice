# LeetCode 121. 买卖股票的最佳时机
题目链接：https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/

## 题目描述
给定数组 `prices`，`prices[i]` 代表第i天股票价格。
规则：只能**某一天买入**，然后在**之后的某一天卖出**，只能交易一次。
求能拿到的最大利润；如果无法赚钱，返回0。

> 关键点：卖出日期必须在买入日期之后，不能先卖后买。

## 解题思路（一次遍历，贪心算法）
核心想法：遍历每一天，**记录到当前为止的历史最低价格（买入价）**，同时计算今天卖出的利润，不断更新最大利润。
1. 初始化最低价格为第一天价格，最大利润 = 0
2. 从第2天开始逐个遍历：
   - 如果当前价格比记录的最低价更低 → 更新最低价（适合在这里买入）
   - 如果当前价格减去最低价，比已记录最大利润更大 → 更新最大利润
3. 遍历结束，返回最大利润

大白话：一边走一边记住之前最便宜的那天，每天都算如果今天卖掉能赚多少钱，保存赚最多的结果。

### 复杂度分析
- 时间复杂度：$O(n)$，只遍历数组1次，n是数组长度
- 空间复杂度：$O(1)$，只用了2个变量，不随数组变大而占用更多内存

### 踩坑记录
1. 利润初始值必须是 0，股价全程下跌时，选择不交易，利润不能为负数。
2. 函数参数里的数组是指针，不能写`sizeof(prices)/sizeof(prices[0])`求长度。
3. 暴力两层循环写法简单，但大数据会超时，优先贪心。
