# LeetCode 101. 对称二叉树
> 题号：101
> 题目链接：https://leetcode.cn/problems/symmetric-tree/
> 难度：简单
> 标签：二叉树、深度优先搜索、递归

##  题目大意
给定二叉树根节点 `root`，判断这棵二叉树是否**轴对称**。
轴对称含义：以根节点为中轴线，左边子树和右边子树互为镜像。

##  解题思路（大白话）
把问题转化为：**判断两棵树是否镜像**
镜像成立的三个条件：
1. 两个当前节点的值相等
2. 第一棵树的左子树 和 第二棵树的右子树镜像
3. 第一棵树的右子树 和 第二棵树的左子树镜像

递归终止条件：
- 两个节点都为空：返回true
- 一个为空、另一个不为空：返回false

##  复杂度
- 时间复杂度：$O(n)$，n为节点总数，每个节点访问一次
- 空间复杂度：$O(n)$，递归调用栈，最坏是单链树

##  踩坑记录

1. **镜像对比是交叉比较**：`a左 vs b右`，`a右 vs b左`，不要写成 a 左 vs b 左，这是最容易写错的逻辑错误。
2. `stdbool.h`头文件：本地使用`bool`类型必须引入，LeetCode 平台自带。
3. 递归终止条件顺序不能乱：要先判断两个节点是否为空，再取值比较，否则访问`NULL->val`会程序崩溃。
4. 区分 “相等” 和 “镜像相等”：两棵树完全相等是同位置对比；镜像要交叉对比。
