# 栈练习 0002_zf_zhan
## 题目简述
使用C语言实现栈的基础操作：入栈、出栈、判空、打印栈内元素。

## 解题思路
用数组模拟栈结构，设置top变量标记栈顶位置。
入栈：top向后移动，存入数据；
出栈：取出top位置元素，top向前回退；
需要提前判断栈满、栈空边界，防止越界访问。

## 复杂度
入栈、出栈操作：O(1)

## 踩坑记录
1. 栈空的时候不能执行出栈，要做判断，不然会读取非法内存
2. 数组下标边界容易搞错，top的初始值定义要统一
3. 栈满继续入栈会造成数组越界，必须增加判断

## 测试样例
依次入栈：10,20,30
出栈输出顺序：30，20，10
