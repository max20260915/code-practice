## 📌 仓库说明

本仓库为**C 语言学习与算法刷题作品集**，所有代码均为本地手写调试，在 VS Code+MinGW 环境验证，记录学习思考、踩坑过程，不只是单纯存放答案。

> 
> 仓库分工：
> 
> 
> - 📂 当前仓库：C 基础语法、数据结构、LeetCode 算法题（链表、栈、二叉树、动态规划等）
> - 📂 STM32 新仓库：单片机外设、驱动、电机控制、机器人综合项目（嵌入式工程）

## 🎯 学习目标

机器人工程专业，主攻嵌入式 + 运动控制方向。
C 语言是 STM32 开发的核心语言，刷题目的：

1. 夯实 C 语言指针、内存、结构体基础（嵌入式高频考点）
2. 训练逻辑思维，掌握链表、栈、树等常用数据结构
3. 养成调试习惯，记录 BUG，积累工程排错经验

## 🛠 开发环境

- 编辑器：VS Code
- 编译器：MinGW-w64
- 语言：标准 C 语言（C99）
- 运行方式：终端 gcc 编译运行
